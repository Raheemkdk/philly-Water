# 🍧 Philly Water — Two Street Water Ice

A Philadelphia-inspired landing page for **Two Street Water Ice**, a neighborhood water ice stand in South Philadelphia.

Built using **HTML5 and CSS3**, this project showcases frontend web development, page layout, visual styling, and user-friendly navigation through a locally inspired business website.

Live Link: https://phillywater.netlify.app/

## 🌟 Project Overview

<img width="1528" height="3003" alt="philly-water" src="https://github.com/user-attachments/assets/98ebf343-919f-4dab-8cf3-a2162a578956" />

Philly Water is a static website designed to capture the character of a traditional Philadelphia water ice stand.

The website features a colorful menu, cup sizes, pricing, seasonal information, and a location section. Its design emphasizes local culture, clear information, and an engaging browsing experience.

The project demonstrates how frontend technologies can be used to create a branded website for a small business.

## ✨ Features

- **Custom landing page:** A welcoming homepage with Philadelphia-inspired branding and messaging.
- **Flavor menu:** Displays classic water ice flavors, including Cherry, Lemon, Blue Raspberry, Mango, and Cotton Candy.
- **Weekly special:** Highlights a featured seasonal flavor.
- **Pricing section:** Shows available serving sizes and prices, including gelati.
- **Navigation links:** Allows visitors to jump between the flavors, sizes, and location sections.
- **Business information:** Displays seasonal hours, location details, and customer information.
- **Custom styling:** Uses CSS to create a distinctive visual identity.
- **Typography:** Incorporates Google Fonts, including Titan One and Nunito.
